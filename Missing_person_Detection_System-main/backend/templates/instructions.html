How to track missing subjects

1

Register a Data Target

Navigate to the UPLOAD PERSONS screen. Provide the subject's legal name, and upload a clear, forward-facing photo without sunglasses or obtrusive masks. Our software instantly calculates an encrypted matrix coordinate (biometric embedding) of their face.

Pro Tip: Using images directly sourced from ID cards yields >98% true-positive matches in varying light fields.
2

Configure Data Streams

Navigate to the LIVE STREAM tab. Deploy streams dynamically by adding RTSP endpoints directly linked to your CCTV system or drone payloads. Enter the IP configuration in the Add Stream widget on the dashboard.

3

Monitor and Alert

Launch the stream by hitting Start. The dashboard binds WebSockets representing live data from configured models. We utilize localized YOLO inference and remote InsightFace execution.

Matches scaling above a 0.55 similarity ratio trigger instantaneous Red Alerts deployed across UI boundaries and cataloged in the Admin Evidence Vault.

Audit Compliance: All deployments and alerts are written chronologically and preserved per international law.
4

Perform Manual Scans

Need offline verification? The CAMERA DETECTION suite allows field agents deploying laptops in local zones to snapshot individuals and test them asynchronously against the master embedding list.
